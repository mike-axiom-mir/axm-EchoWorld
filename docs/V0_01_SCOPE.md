# EchoWorld v0.01 Scope

The first version is intentionally a tiny experimental proof.

## In scope

- deterministic 16x16 canonical world state;
- stable persistent cell identity;
- bounded cell memory;
- deterministic importance scoring and compaction;
- wake/sleep state transitions;
- bounded event-relevant specialist proposal receipts;
- deterministic event commit ordering;
- bounded first-hop handoff receipts;
- persistence/reload proof;
- canonical hashing and A/B memory-off/memory-on equivalence tests;
- explicit evidence and claim boundaries.

## Out of scope

- AI or model integration;
- production rendering/gameplay;
- networking/multiplayer;
- production persistence database;
- massive-world performance claims;
- autonomous permanent agent swarms;
- story quality claims;
- VR/movie manifestation.
