# EchoWorld Engineering Principles

1. Truth commits before memory.
2. Memory can disagree subjectively but cannot rewrite canonical physics.
3. Specialists propose bounded work and do not gain hidden authority.
4. Worker completion order must not define truth.
5. Handoffs are bounded events, not direct neighbor ownership.
6. Persistent identity does not require permanent active compute.
7. Evidence outranks narrative confidence.
8. Build and measure before promoting experimental claims.
9. No AI in v0.01.
10. One chat works in one lane.
